# 📚 Education Platform (ASP.NET Core MVC)

An online educational platform built using ASP.NET Core MVC that allows students to access courses, view study materials, and manage their learning process.

---

## 🚀 Features

- Student Registration & Login
- Course Management
- Upload & View Study Materials
- Basic Admin Control
- Simple & User-Friendly UI

---

## 🛠️ Technologies Used

- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- Razor Views
- Bootstrap

---

## 📂 Project Structure

- **Models** – Contains application entities  
- **Views** – Razor UI pages  
- **Controllers** – Handles user requests and application logic  
- **Data** – Database context & configurations
